# Vehicle image catalogue

These 20 generic, unbranded vehicle cutouts are generated project assets used by the public QR document page.

The browser loads only the selected WebP file. `vehicle_image_type` is stored in the inspector document payload; when it is `auto`, the page falls back to keyword matching from `vehicle_model`, cargo and trailer information.

Available keys: `sedan`, `hatchback`, `suv`, `minivan`, `pickup`, `microbus`, `city-bus`, `coach-bus`, `cargo-van`, `box-truck`, `dump-truck`, `tanker-truck`, `refrigerated-truck`, `flatbed-truck`, `tractor-unit`, `box-semitrailer`, `curtain-semitrailer`, `container-truck`, `car-carrier`, `heavy-haul-lowboy`.

Generation style: photorealistic neutral vehicle-catalog cutout, transparent background, no people, no logos, no brand badges, no readable plate, consistent three-quarter front view.
